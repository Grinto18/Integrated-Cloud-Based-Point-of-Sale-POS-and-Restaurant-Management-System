# دليل التثبيت والتشغيل — نظام نقاط البيع القصر الذهبي (GOLDEN PALACE POS)

## 1. المتطلبات النظامية
- **نظام التشغيل:** Windows 11 (64-bit) موصى به، أو Windows 7 SP1 (64-bit) مع تحديثات Universal C Runtime و Visual C++ Redistributable 2015–2022 (x64).
- **المعالج والذاكرة:** معالج ثنائي النواة 64-bit على الأقل، ذاكرة 4 GB RAM (يفضّل 8 GB).
- **مساحة القرص:** 500 MB على الأقل للبرنامج وقاعدة البيانات والنسخ الاحتياطية اليومية.
- **الطابعة الحرارية:** طابعة حرارية 80mm أو 58mm معرّفة على Windows Spooler (أو طابعة شبكة IP).

## 2. خطوات التثبيت على Windows
1. شغّل ملف المثبّت الرسمي:
   `GOLDEN-PALACE-POS-Setup-1.0.0-x64.exe`
2. اختر مجلد التثبيت (أو اترك المسار الافتراضي) واضغط **التالي (Next)** ثم **تثبيت (Install)**.
3. عند انتهاء التثبيت، ستظهر أيقونة **GOLDEN PALACE POS** على سطح المكتب وفي قائمة ابدأ.
4. عند إلغاء التثبيت مستقبلاً، **لا يتم حذف قاعدة البيانات** أو النسخ الاحتياطية (`%APPDATA%\GOLDEN PALACE POS`).

## 3. التشغيل الأول وإعداد حساب المدير
1. افتح التطبيق من سطح المكتب.
2. عند أول تشغيل على قاعدة بيانات فارغة، ستظهر شاشة **الإعداد الأولي للمدير (First-Run Setup)**.
3. أنشئ حساب المدير الرئيسي (اسم المستخدم، الاسم الكامل، كلمة مرور قوية، ورمز PIN اختياري).
4. لا توجد كلمات مرور افتراضية مكشوفة؛ احتفظ ببيانات المدير في مكان آمن.

## 4. استيراد قائمة الطعام الرسمية (12 تصنيفاً • 105 منتجاً • 20 حجماً للبيتزا)
1. سجّل الدخول بحساب **المدير (ADMIN / OWNER)**.
2. من القائمة الجانبية افتح **استيراد القائمة (Import Menu)** أو من داخل **المنتجات ← استيراد القائمة**.
3. اختر أحد الملفات الرسمية من المجلد `data/official-menu/`:
   - `golden_palace_official_menu.xlsx` (Excel — موصى به)
   - أو `golden_palace_official_menu.csv` (UTF-8)
   - أو `golden_palace_official_menu.json`
4. راجع شاشة المعاينة (التصنيفات: 12، المنتجات: 105، الأحجام: 20، المكررات: 0، الأخطاء: 0).
5. فعّل خانة **تأكيد المدير الصريح** ثم اضغط **تأكيد واستيراد**.
6. يقوم النظام تلقائياً بإنشاء نسخة احتياطية موثّقة لقاعدة البيانات قبل الحفظ، ثم يستورد القائمة بالكامل ضمن معاملة واحدة آمنة.

## 5. إعداد الإضافات (اختياري)
- تبدأ قائمة الإضافات فارغة افتراضياً (بدون إضافات مفروضة).
- لإضافة خيارات مثل (جبن إضافي، صوص خاص...) افتح **المنتجات ← الإضافات** وأضف كل خيار مع سعره بالدينار الجزائري (DA).
